Integrating Vite with Ngrok allows you to expose your local development server to the internet, making it accessible for testing or sharing. Below is a step-by-step guide to set up this integration using the vite-plugin-ngrok.

Install the Plugin

Navigate to your Vite project directory.

Install the vite-plugin-ngrok package:

npm install -D vite-plugin-ngrok
Copy
Configure Vite with Ngrok

Open or create a vite.config.ts file in your project root.

Add the following configuration: 
import { defineConfig } from 'vite'; 
import { ngrok } from 'vite-plugin-ngrok'; export default defineConfig({ plugins: [ ngrok('YOUR_NGROK_AUTH_TOKEN'), // Replace with your Ngrok auth token ], }); Secure Token Handling: Avoid hardcoding your Ngrok token in the code. Instead, use environment variables: import { loadEnv, defineConfig } from 'vite'; import { ngrok } from 'vite-plugin-ngrok'; const { NGROK_AUTH_TOKEN } = loadEnv('', process.cwd(), 'NGROK'); export default defineConfig({ plugins: [ ngrok({ authtoken: NGROK_AUTH_TOKEN }), ], });

Start the Development Server

Run your Vite development server as usual:

npm run dev
Copy
The plugin will automatically create an Ngrok tunnel and provide a public URL for your local server.

Advanced Configuration

You can customize Ngrok settings by passing an object:

ngrok({
authtoken: 'YOUR_NGROK_AUTH_TOKEN',
domain: 'custom-domain.ngrok.app',
compression: true,
});

Common Issues

If you encounter HTTPS errors, ensure that both Vite and Ngrok are running on secure protocols.

Use <meta http-equiv="Content-Security-Policy" content="upgrade-insecure-requests"> in your HTML if necessary.

This setup simplifies sharing your Vite project over the internet while maintaining flexibility and security.
